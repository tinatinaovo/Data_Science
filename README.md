## 🧠 Key Takeaways

- Choose metrics based on **business cost**, not accuracy
- **Recall** matters more than precision in medical/risk contexts
- **Feature engineering** (lags, polynomials) changes model behavior fundamentally
- Structure projects for **reproducibility** (notebook + README + report)
